[![Regression tests](https://github.com/wuyufei0817/AI_Course_Project/actions/workflows/tests.yml/badge.svg)](https://github.com/wuyufei0817/AI_Course_Project/actions/workflows/tests.yml)

**本版新增 Animals 动物探险课。** 从 [快速上手](先看我.md) 进入投屏、10 页答辩与连续演示脚本。原拓展工具的通用题库仍可从教学工作台打开。

小学三年级 **Animals** 一份课例，串起“备课 → 课件 → 课堂活动 → 练习 → 发布 → 提交 → 反馈 → 订正 → 复盘”的完整教学链路。
教师主导、内容可编辑、结果可核对。

- 应用：Python 标准库 + SQLite + 原生 JS，**无需安装第三方包、无需构建**
- 三种角色：教师 / 学生 / 家长，权限在接口层校验
- 产物：教案 PDF、可编辑 PPTX、词卡任务卡、学生卷与独立答案页、题库 XLSX、教学日志
- 验证：[课堂展示版核验](交付物/05_整合与核验/课堂展示版核验.md)及[基线记录](交付物/05_整合与核验/本次验证.md)
- 整合：同一站点内同时提供教学助手（教师/学生/家长）与 AI 英语教学工作坊（找茬、提示词、游戏工坊、培训演示）

## 1. 快速开始

### Windows

双击根目录的“启动演示.bat”，或在该目录打开终端执行：

    py app\server.py --port 8848

### macOS / Linux

    python3 app/server.py --port 8848

浏览器打开 **http://127.0.0.1:8848/** 。首次启动会自动创建 app/data/ai4en.db 并写入演示数据。
需要 Python 3.9 及以上；不需要 pip install。

> 端口被占用时换一个：py app\server.py --port 8849，然后访问对应端口。

## 2. 8 分钟演示路径

教师端已按教学步骤重排为四组十一个左栏入口。顶部“当前课例”在模块间保留，可切换课例；课例库支持搜索、年级与状态筛选。首页显示本人任务的待复核、待订正及未提交人次。详细说明见 [教师工作台改版说明](docs/教师工作台改版说明.md)。

1. **工作台** → 打开 Animals: What's this?（已审核）
2. **教案备课** → 改一处活动时间 → 保存草稿 → 审核通过（演示“可编辑、可审核”）
3. **课件资源** → 逐页编辑 → 导出 PPTX；打印词卡
4. **课堂活动** → 投屏演示：词义配对 4 组、句子排序 → 重玩一轮
5. **练习与小测** → 改一道题 / 看两种支持方式
6. **任务发布** → 预览学生页 → 发布（冻结题目与答案快照）
7. 退出，用 s_zhang 登录 **学生端** → 提交 / 查看已确认反馈 → 提交订正
8. 用 t_wang 回到 **批改与订正** → 改一条反馈并确认 → **学情分析**查看提交率与错误率 → **教学日志**据统计生成反思草稿并保存
9. 用 p_zhang 登录 **家长端** → 只看到自己孩子的状态与已确认反馈

拓展入口：教师端 **课堂互动 → 拓展课堂玩法**（约 1 分钟，按评委兴趣选标签），思维导图从 **教案备课**进入。工作坊的游戏工坊、水果线索卡与完整版的游戏闯关、数字人、思维导图都内嵌在工作台里，顶栏不变；配色与字体由 `app/web/static/theme/ai4en-bridge.css` 统一。三者的数据边界见 `交付物/05_整合与核验/三项目整合说明.md`。

新版 [8 分钟课堂展示脚本](交付物/04_答辩材料/Animals课堂展示脚本.md)含游戏与 Lily 问答。

### 4.3 实现与使用要求

- **教师可控**：生成内容只是候选稿；修改教案/题目会让课例回到“草稿”，必须重新审核才能发布；开放题反馈确认后才进入学生页面。
- **流程可运行**：内置班级、虚拟账号与演示数据，可完整走通发布 → 提交 → 反馈 → 订正 → 结果查看。
- **材料可交付**：教案与任务单可打印为 PDF；课件可导出可编辑 PPTX；学生卷与教师答案分开。
- **结果可核对**：统计来自真实提交记录；模型失败有提示并写入日志；示例内容、真实模型输出、规则生成、教师手工编辑分别标注。
- **访问有范围**：教师仅本人课例与班级，学生仅本人任务与作答，家长仅绑定孩子；越界请求在后端返回 403。
- **学生端有独立学习档案**：学习概览、我的任务、单词卡、错题本、订正记录、学习报告、使用说明，全部只读本人数据，不出现标准答案与班级排名。
- **界面不使用 emoji**：界面图形全部为本地线性 SVG 图标（`static/theme/icons.js`），词卡与配图使用本地 WebP 插画（`static/illustrations/`、`static/words/`）。完整版历史内容里的 emoji 会在渲染前由 `static/theme/emoji.js` 统一替换为图标或移除。
- **素材来源**：页面插画为项目内生成图（`static/illustrations/README.md`）；动物词卡来自 Icons8 Color 图标集（免费许可，需标注），见 `static/words/CREDITS.md`。

## 5. 权限与数据规则

| 角色 | 可以操作 | 可访问范围 |
| --- | --- | --- |
| 教师 | 建课、生成、编辑、审核、发布、批改、复盘、导出 | 本人课例与任教班级 |
| 学生 | 查看任务、提交、看已确认反馈、订正 | 本人的任务与作答 |
| 家长 | 查看孩子任务、状态、已确认反馈（只读） | 绑定孩子的允许内容 |

- 学生接口统一剥离 answer / accept / analysis / criteria 字段；答案页与导出仅教师可用。
- 任务发布时把题目与答案冻结为快照，之后修改课例不影响已发布任务；改题请复制成新任务。
- 订正时把原作答写入 revisions，submissions.answers 保存最新版本，教师可对照两个版本。
- 反馈确认后 feedback.status = confirmed，学生端才返回 final 文本；草稿永远不下发。

## 6. 模型配置（可选）

默认**未配置模型**，生成接口使用内置示例模板，界面与日志都标记为“示例内容”，不能当作真实模型调用的证据。

配置后，生成教案、练习和反馈草稿会调用后端模型（OpenAI 兼容 /chat/completions）：

    set AI4EN_LLM_BASE_URL=https://api.example.com/v1
    set AI4EN_LLM_API_KEY=sk-xxxx
    set AI4EN_LLM_MODEL=gpt-4o-mini
    py app\server.py --port 8848

- 密钥只在后端读取，浏览器拿不到。
- 调用失败返回 502：保留输入与已保存草稿，页面显示原因与“重试”，并写入生成日志（gen_logs.status = failed）。
- 演示失败：教案页点“演示：模型失败”，可在不配置模型的情况下验证异常链路。

### 助教完整版（`/static/lab/`）的数字人与提示词教练

完整版沿用原项目的 DeepSeek 配置方式，代理已并入本服务的 `POST /api/chat`（不需要再跑 Node）：

    set DEEPSEEK_API_KEY=sk-xxxx
    set DEEPSEEK_MODEL=deepseek-chat
    py app\server.py --port 8848

也可以在项目根目录新建 `config.json`：`{"apiKey": "sk-xxxx"}`。未配置时数字人自动走脚本对话，页面右上角显示“演示模式”；配好后徽章变为“AI 自由对话”。`/api/health` 会返回 `hasKey` 供页面判断。

## 7. 数据重置

    cd app
    py -c "from ai4en import seed; print(seed.run(reset=True))"

会清空并重建演示数据（含自增编号）。也可以直接删除 app/data/ai4en.db 后重启。

## 8. 验收与自测

    py tests\smoke_test.py
    py tests\acceptance.py http://127.0.0.1:8851
    py tests\lab_test.py http://127.0.0.1:8848

`smoke_test.py` 会在临时目录建独立数据库并另起服务，跑完 50 项回归用例；设置 `AI4EN_BASE` 时则直接连已有服务。
`acceptance.py` 连一个已启动的临时服务，跑 35 项整合验收（工作坊入口、局部再生成、课堂观察、听写、截止时间等）。
`lab_test.py` 对已启动的服务检查完整版入口、脚本、`hasKey` 与未配置 Key 时的 503。
三套脚本都输出“预期 / 实际”，不会写入演示数据库。结果同步记录在 交付物/03_验证记录/验证记录.md、验证记录.xlsx，
以及 交付物/05_整合与核验/本次验证.md。

## 10. 已知限制

- 试用规模为 1 个班 6 名学生，没有真实课堂的长期数据；不声称“显著提高成绩”。
- 未配置模型时全部生成内容为示例模板，质量不代表真实模型能力。
- PPTX 使用固定 6 页模板，复杂版式与图片需要教师替换。
- 家长端为只读，不含通知；学生端不支持附件与语音作答。
