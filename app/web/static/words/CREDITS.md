# 词卡插图来源

本目录的四张动物词卡（cat / dog / panda / frog）来自 Icons8 的 Color 图标集：

- 来源：https://icons8.com/icons/set/animals
- 下载地址：https://img.icons8.com/color/480/{cat,dog,panda,frog}.png
- 许可：Icons8 免费许可（https://icons8.com/license），要求在使用处标注 Icons8 链接。
- 处理：裁掉透明边、留 8% 呼吸空间、缩放为 256×256 并转为 WebP（每张约 10 KB）。

页面中通过 `/static/words/<word>.webp` 引用，用于学生单词卡、课堂词汇砖、配对游戏与打印词卡。
