# UI 打磨说明（2026-11-11）

本轮围绕视觉一致性、内容层次与移动端导航，不调整教学评价、作答和权限规则。

## 页面变化

- 统一组件：主应用、工作坊、课堂、完整版与答辩入口均加载 `app/web/static/theme/ui-polish.css`。统一卡片圆角、按钮高度和焦点样式，保留各场景的原有配色特点。
- 字体层次：主应用保留衬线大标题；正文说明与功能分区统一采用无衬线字，字号、行高和间距分层设置。
- 学生端：合并错题本的重复提示，移除词卡重复的操作提示。引导步骤使用圆形编号，插画使用固定尺寸槽位。
- 词卡：图片、英文、展开内容和自我检查按钮收为一张完整卡片。桌面按钮等宽并排，手机按钮等宽纵排；展开卡片后同一行的按钮区域保持底部对齐。
- 空状态：复用本地动物插画，让无任务、无筛选结果等状态更友好；装饰图使用空 alt，不增加读屏负担。
- 手机与平板：980px 以下使用原生 details 折叠菜单替代横向导航；保留分组、图标和当前页面标记。点击链接或外部区域关闭，Escape 关闭并把焦点返回菜单按钮。

## 验证

- 浏览器检查学生端七个模块及教师工作台；检查课堂、工作坊、完整版和答辩四个静态入口，无页面脚本异常。
- 检查 320px、390px、768px 学生词卡布局，无整页横向溢出。
- 验证手机菜单七个入口可见、Escape 关闭与焦点恢复、点击入口后关闭并正常导航。
- 验证词卡自我标记和筛选继续正常；减少动态效果设置仍生效。
- 功能回归 `tests/smoke_test.py`：50 / 50 通过，使用独立临时数据库。
