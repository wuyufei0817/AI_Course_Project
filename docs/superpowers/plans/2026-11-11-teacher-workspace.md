# Teacher Workspace Implementation Plan

**Goal:** 将教师端整理为围绕当前课例的分组工作台，支持前后端完整操作。

**Architecture:** 保留 Python 标准库、SQLite、原生 JS 与既有 hash 地址。新增教师工作台前端模块与教师专用汇总接口；拆分结果页的渲染职责，复用原业务操作与权限校验。

**Tech Stack:** Python 3.9+ / SQLite / JavaScript / CSS，运行不新增依赖。

## Design and scope

- 使用已有 checkout 的 feature/teacher-workspace 分支；不推送或合并。
- 四组十一个入口：工作台、课例库；教案备课、课件与教具、课堂互动、练习与命题；任务管理、批改与订正、学情分析、教学日志；教师成长与帮助。
- 当前课例选择器保留模块，地址支持刷新与直达，选择按教师账号隔离；未保存编辑提供离开提醒。
- 结果页分为批改列表、学情统计与错题组卷、独立日志；观察迁入课堂，听写迁入练习。
- 工作台统计来自本人课例下的任务与作答，区分待复核项、待订正份数、未提交人次；草稿任务不算作学生待办。
- 课堂观察允许无任务保存，使用本班学生；日志允许无任务手写保存；资源只在准备好时提供下载。
- 保持既有发布快照、反馈确认、订正与权限规则，保留旧地址及学生家长行为。
- 沿用 #3F8F68、#F4FAF6、#153027、#5F7268，使用系统中文字体；左栏紧凑分组，右侧按工作任务布局，小屏折叠导航。

## Review focus

- 直接打开批改页、首次登录与刷新时，课例上下文必须正确。
- 切换课例不能沿用上节课任务或日志输入；拒绝离开时表单应保持。
- 无课例、无任务、无作答时不显示失效下载或虚构统计。
- 其他教师、学生、家长不能读取教师汇总或写入观察。
- 草稿不计入待提交，已结束任务不算当前催交；多任务未提交按人次显示。
