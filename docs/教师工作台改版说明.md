# 教师工作台改版说明

原教师左栏只有工作台、拓展和使用指南，大多数业务藏在课例页；结果与日志页同时承载批改、统计、错题、反思、观察和听写。本次调整将教师常用任务直接放到左栏，拆开右侧长页面。

## 导航与功能

| 分组 | 模块 |
| --- | --- |
| 教学总览 | 工作台、课例库 |
| 课前与课堂 | 教案备课、课件与教具、课堂互动、练习与命题 |
| 课后与评价 | 任务管理、批改与订正、学情分析、教学日志 |
| 教师支持 | 教师成长与帮助 |

- 顶部当前课例选择器保留当前模块，切换到另一节课；页面地址可刷新和直达。最近选择按教师账号保存在本机，班级数据仍在 SQLite。
- 工作台聚合本人已发布任务的待复核反馈项、待订正份数、进行中任务未提交人次，可进入相应课例处理。草稿任务不计入学生待办，已结束任务不计入当前催交。
- 课例库支持标题/主题/目标词搜索、年级和状态筛选，以及新建和复制。
- 课件与教具展示本课资源准备状态；学生卷和答案页可选择已发布任务，未准备资源提供准备入口。
- 批改与订正独立展示学生作答，支持待复核/待订正/已订正筛选；原反馈确认与双版本作答规则保留。
- 学情分析集中展示提交统计、单题情况和错题组卷，不混入拓展项目的演示数据。
- 教学日志可独立手写保存，也可据选定任务统计生成草稿；保存后刷新仍在，并保留历史。修复了原日志输入没有绑定到日志表单的问题。
- 课堂观察移入课堂互动，无需先发布任务；听写登记移入练习与命题，仍为课例级记录。
- 找茬侦探和提示词修理铺在教师成长与帮助中内嵌打开；游戏、数字人归入课堂互动，思维导图从备课进入。
- 教师编辑离开前显示未保存提醒。切换课例重置旧任务表单，避免课例之间混用。

## 本地运行与演示

```powershell
python app/server.py --port 8848
```

打开 http://127.0.0.1:8848，使用 `t_wang / teach123` 登录。

建议展示：工作台待办 → 选择 Animals → 左栏进入批改与订正 → 学情分析 → 教学日志保存并刷新 → 切换 My Family 记录课堂观察 → 课例库筛选 → 教师成长练习。

本次没有新增 22 单元教材库、真实语音评分、OCR 批改或机构后台；拓展素材仍有明确演示边界。运行无新增第三方依赖，无数据库结构迁移。

## PR 描述建议

教师端原来只有三个左栏入口，结果与日志页承载过多操作。本次将其整理为四组十一个教学模块，通过当前课例选择器保持上下文，并拆分批改、学情和教学日志。补充真实待办汇总、课例筛选、本课资源状态，以及发布任务前的课堂观察记录；复用原发布快照和反馈确认规则，应用运行仍然零第三方依赖。
